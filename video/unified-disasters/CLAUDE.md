# HyperFrames — Unified Disasters reel

~58s narrated tour of the Unified Disasters dashboard (multi-source ingest, map, loans, webcams, AI).

## Commands

```bash
npm run dev          # preview (background)
npm run check        # lint + validate
npm run render       # renders/*.mp4
npm run narration    # TTS via npm start at repo root
```

## Publish

Copy latest render to `public/finance/assets/video/unified-disasters-reel.mp4`.

See `frame.md` and `scenes.json`.
