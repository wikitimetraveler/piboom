# HyperFrames — DevConnect Labs tech stack reel

~58s narrated tour of the platform stack (Node/Postgres, AI, Encompass, frontend, data/maps).

## Commands

```bash
npm run dev          # preview (background)
npm run check        # lint + validate
npm run render       # renders/*.mp4
npm run narration    # TTS via npm start at repo root
```

## Publish

Copy latest render to `public/shared/assets/video/tech-stack-reel.mp4`.

See `frame.md` and `scenes.json`.
