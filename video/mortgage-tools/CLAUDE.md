# HyperFrames — DevConnect mortgage tools reel

~66s narrated tour of Worksheets, Encompass, disasters, and AI tools.

## Commands

```bash
npm run dev          # preview (background)
npm run check        # lint + validate
npm run render       # renders/*.mp4
npm run narration    # TTS via npm start at repo root
```

## Publish

Copy latest render to `public/finance/assets/video/mortgage-tools-reel.mp4`.

See `frame.md` and `scenes.json`.
