# HyperFrames — Music Research reel

~58s narrated tour of Music Research (Historian, timeline, map, discovery suite).

## Commands

```bash
npm run dev          # preview (background)
npm run check        # lint + validate
npm run render       # renders/*.mp4
npm run narration    # TTS via npm start at repo root
```

## Publish

Copy latest render to `public/music/assets/video/music-research-reel.mp4`.

See `frame.md` and `scenes.json`.
