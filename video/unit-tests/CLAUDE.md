# HyperFrames — DevConnect Unit Test tool reel

~58s narrated tour of the Encompass Unit Test tool (generate, grid, run, library, Learn Mode).

## Commands

```bash
npm run dev          # preview (background)
npm run check        # lint + validate
npm run render       # renders/*.mp4
npm run narration    # TTS via npm start at repo root
```

## Publish

Copy latest render to `public/finance/assets/video/unit-tests-reel.mp4`.

**Assets:** `assets/narration/scene0–6.mp3` · `assets/screenshots/*.svg` (swap to PNG later — see `assets/screenshots/README.md`)

See `frame.md`, `scenes.json`, and `assets/screenshots/manifest.json`.
