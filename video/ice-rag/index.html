Lane AI Labs

Hybrid RAG for Encompass

Two knowledge stores ground the assistants: ICE artifacts plus Developer Connect docs. Keyword JSON always works; pgvector adds semantic recall when Postgres and OpenAI are available.

Contract
1keyword JSON fallback
2pgvector when ready
3executionAllowed=false

Stores

ICE · Dev Connect docs

ice-knowledge.service reads ice-sources.json and ice_knowledge_chunks. encompass-docs.service reads encompass-docs.json and encompass_docs_chunks. Same hybrid pattern, separate tables.

Services
ice-knowledge.service.js encompass-docs.service.js ice_knowledge_chunks encompass_docs_chunks

Ingest

Repos · Postman · docs

Drop ICE sample repos, Postman collections, and Dev Connect snapshots under knowledge-sources/ice/. Scrape merges Developer Connect pages by title/category — partial scrapes do not wipe the seed.

Layout
rknowledge-sources/ice/repos/
pknowledge-sources/ice/postman/
dknowledge-sources/ice/docs/

Build

Normalize · hash · embed

build:ice-knowledge normalizes into ice-sources.json. scrape:encompass-docs refreshes docs JSON. Both upsert pgvector rows by content_hash — unchanged chunks skip re-embed.

Jobs
npm run build:ice-knowledge npm run scrape:encompass-docs content_hash idempotent upsert

Vectors

1536-d · HNSW cosine

text-embedding-3-small via embedding-utils. ensureKnowledgeVectorTable creates embedding vector(1536) plus HNSW cosine. Search orders by embedding <=> query; score = 1 − distance.

Schema
eembedding vector(1536)
iHNSW cosine index
qORDER BY embedding <=> $1

Search

Promise.all · merge · boost

search() runs searchVector and searchKeyword in parallel. Vector hits get +5 score boost, then dedupe by repo|url|title. No DB / pgvector / key → vector returns []; keyword still answers.

Merge
vsearchVector → boost +5
ksearchKeyword → boost 0
∪dedupe · sort · limit

Consumers

Assistant · Unit Tests AI

encompass-assistant.controller and unit-tests-ai search both stores, assemble context, then call the LLM. executionAllowed stays false — retrieval only, never live ICE API execution from RAG hits.

Surface
encompass-assistant.controller.js /api/encompass-assistant/* executionAllowed=false

Ops

refresh:encompass-knowledge

Combined refresh scrapes docs then rebuilds ICE. SKIP_EMBED flags keep JSON-only. GraphRAG on graph_nodes.embedding is a sibling path for disaster pipeline AI — not live /near proximity.
