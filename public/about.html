Platform overview

I'm David Lane, engineer behind DevConnect Labs. The platform centers on Encompass integration — OAuth-backed APIs, loan pipeline and custom-field tooling — plus unified disaster monitoring. Many tools plug into live Encompass when configured; others run standalone with real feeds or offline mock data for demos and CI.

I ship service-layer Node.js APIs, PostgreSQL-backed features, and LangChain + OpenAI assistants with persistent memory. OpenAI Vision (GPT-4o) powers image-driven tooling such as Automator field parsing and manifest review; HeyGen handles avatar video for demos and QR-triggered guide popups. The frontend is Bootstrap and vanilla JavaScript — no React — with AG Grid and DataTables where tables matter.

On hub pages, press Ctrl+K to search all tools. Demo mode narrows the catalog to Worksheets and Encompass.
