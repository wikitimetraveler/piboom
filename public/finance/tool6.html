How to Use The Transformer

Getting Started
  1. Paste your XML content into the text area above, or select an XML file using the file input
  2. Click the "Transform" button to process the XML
  3. View the results in the table below
Features
  • Field Search: Use the search box to find specific fields by ID or label
  • Editable Table: Click any cell to edit its content
  • JSON Output: View and edit the JSON representation of your data
  • Export Options: Export your data to Excel, PDF, or copy to clipboard
Understanding the Output
  • FieldID: The unique identifier for each field
  • Label: The display name of the field
  • CType: The control type (e.g., DropdownBox)
  • Calendar: Indicates if the field is a date field
  • Method: The method used to determine the field's value
Tips
  • Fields appearing in AdvancedCodeDependencies or AdvancedCodeXml are automatically excluded
  • Use the search feature to quickly find specific fields
  • You can edit the JSON output and update the table using the "Update Table from JSON" button
  • Changes made to the table can be saved back to JSON using the "Update JSON from Table" button
