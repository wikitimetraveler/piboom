AI mode returns 0–50 “difficulty” points from a field summary (loan type, amounts, DTI/LTV, FICO, program, investor, etc.). Map your tenant income type / self-employed / condition count / investor program fields into rules, or add those ids to pipeline + rules. Example placeholders in default rules: Fields.CX.BORROWER.INCOME.TYPE, Fields.CX.BORROWER.SELF.EMPLOYED, Fields.CX.UW.CONDITION.COUNT, Fields.CX.INVESTOR.PROGRAM (rename to match your site).
