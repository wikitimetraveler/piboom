    Postgres data model

    Unified Disasters reads shared Postgres tables—no page-specific schema. Events refresh on a 90-day window.

    Fact tables

    • disasters — FEMA, FIRMS, USGS, NWS, NHC events (grid + map)
    • fire_cameras — fixed hazard webcams (not disaster rows)
    • loans — mocked pipeline properties, ops triage scores (not probabilities), flood zones

    Spatial link (live dashboard)

    ModelHowUsed here
    Spatial (live) GET /api/disasters/near (PostGIS or Haversine) Live selection, nearby loans & cameras — operational truth

    Radius search powers the grid selection strip, loan map pins, and hazard webcam panel on this page. Do not equate this with graph NEAR edges (those are as-of last reseed only).

    Graph link (multi-hop)

    ModelHowUsed here
    Graph graph_nodes + graph_edges (reseed) Impact Graph prototype

    Graph chain: county → disaster → zip → loan → milestone → processor, plus NEAR edges from spatial seed (~50 mi, per-disaster cap). Graph NEAR carries seeded_at in edge metadata — stale until reseed; live proximity uses GET /api/disasters/near only.

    Edge types (impact graph)

    HAS_DECLARATION, CONTAINS, AFFECTS, NEAR (heuristic link strength, not a probability), CURRENTLY_IN, ASSIGNED_TO
