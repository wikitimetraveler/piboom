Voice Shortcuts

  • "Show grid" Opens the Test Grid accordion.
  • "Show scenarios" Opens the Test Scenarios accordion.
  • "Run tests" Executes the current test run.
  • "Clear data" Clears the loaded test data.
  • "Search for [term]" Filters the grid by the spoken term.
  • "Analyze failures" Sends current test failures to the AI assistant for analysis (after a test run).
  • "Show commands" / "Hide commands" Opens or closes this reference.
