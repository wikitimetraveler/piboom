Generate Unit Test from Custom Field

Select an Encompass custom field with a calculation (e.g. [CUST11FV] tax next-due rollup or [CX.TEST] = 1 + [353]). We will generate SET and COMPARE steps to test it.

The meaningful equals is the assignment after the bracketed field ([FIELD] = …). If you pasted from Excel, drop the spreadsheet’s leading =—this tool parses Encompass calculation text, not an Excel formula cell.

Type to search or click the dropdown arrow. Selected field shows full calculation below.
