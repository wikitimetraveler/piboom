What it is

TPO Connect (Third-Party Originator Connect) is ICE Mortgage Technology’s correspondent / wholesale portal. Brokers and correspondents submit and manage loans; lenders host customized web apps inside TPO Connect via a sandboxed iframe.

Product family Alongside LO Connect and Developer Connect — see glossary.
Integration model Parent (TPO) ↔ child (your HTTPS guest app) via ICE Secure Scripting Framework (SSF).
Loan API shape loan.tpo → LoanContractTPO (company, branch, LO, LP, fees, dates).
Conditions recipient External recipient label in Labs: Borrower / TPO.

Client application (iframe guest)

From ICE’s Encompass TPO Connect Client Application Integration Guide. Your app loads inside the TPO web application and receives user / loan context from the parent.

Prerequisites

  • Serve the client application over HTTPS.
  • Relax SAMEORIGIN so the guest can load in an iframe.

Guest library

Default: elli.ssf.guest-with-polyfill.js (includes IE-friendly polyfills). Use elli.ssf.guest.js only if you already ship your own polyfill before the guest script. 

<script src="https://cdn.elliemae.io/elliemae/core/ssf/1.0/elli.ssf.guest-with-polyfill.js"></script>
<script>
  window.addEventListener("load", function () {
    elli.script.guest.create();
  });
</script>

elli.script.guest.create() registers the guest, opens parent↔child messaging, and exposes the TPO context object to your page.

Published SSF objects

Access with await elli.script.getObject('…'). Documented for TPO child apps:

tpoApplication auth loan

tpoApplication

  • getUserData() — FullName, email, contactID, externalOrgID, roles, personas
  • getUserProfileData() — full user profile
  • getExternalOrgDetails() — siteId, company/branch org IDs & names
  • pageRedirect(pageName, { id: loanGuid }) — navigate TPO standard pages

auth

  • getAccessToken() — { access_token, host_name, token_type }
  • getUser() — id, realm, firstName, lastName

loan

  • all() — complete loan data object
  • isReadOnly() — boolean
  • calculate() — calculated loan snapshot
  • merge() — refresh workspace loan from Encompass before returning to TPO (ICE marks this as important) 
async function printAccessToken() {
  const auth = await elli.script.getObject('auth');
  const http = await elli.script.getObject('http');
  const respAccessToken = await auth.getAccessToken();
  const authToken = respAccessToken.token_type + ' ' + respAccessToken.access_token;
  const api = respAccessToken.host_name + '/encompass/v3/system/info';
  const resp = await http.get(api, {
    'Content-Type': 'application/json',
    Authorization: authToken,
  });
  console.log('Encompass Version : ', resp);
}

Token exchange (custom tools / plugins)

Inside LO Connect or TPO Connect, a guest can create an auth code and exchange it for a Developer Connect access token (see ICE sample imt-exp20-token-exchange). 

const http = await elli.script.getObject('http');
const auth = await elli.script.getObject('auth');
const authCode = await auth.createAuthCode();
const tokenResp = await http.post(
  'http://localhost:8081/api/token',
  { 'Content-Type': 'application/json' },
  { authCode }
);
const accessToken = tokenResp.body.access_token;

Sample service listens on port 8081; configure oauth.js with host, clientId, and secret for the target Encompass environment.
