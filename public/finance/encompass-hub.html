Voice Shortcuts

  • "Refresh status" Checks the Encompass OAuth token health.
  • "Load pipeline" Runs the current filter set against Developer Connect.
  • "Set state to California" Updates the state filter (also works for counties & limits).
  • "Select first loan" Highlights a specific row and loads its details.
  • "Clear filters" Resets filters back to their defaults.
  • "Show commands" / "Hide commands" Opens or closes this reference.
